Before the repo's visibility changes (Sam's action, after every box is ticked). Spec: `docs/superpowers/specs/2026-10-20-venue-arb-dashboard-design.md` section 7.

- [x] **Secret scan of full history is clean.** 2026-10-20, gitleaks 8.30.1, from the repo root:

  ```bash
  gitleaks detect --source . --log-opts="--all" --no-banner
  ```

  Result: `100 commits scanned. scanned ~2651667 bytes (2.65 MB) in 807ms. no leaks found` (exit 0). Git history only;
  the git-ignored `.superpowers/` directory is not part of history and was not scanned. Zero findings, so nothing to
  review. Known non-secret identifiers that a scanner could flag, and are fine: `BWS_PROJECT_ID` (below), Polymarket
  `0x...` token and market ids (public identifiers), the `sha256` in `dashboard/static/VENDOR.md`. Re-run before the
  visibility flip if more commits land.
- [ ] **`BWS_PROJECT_ID` decision (Sam).** `mise.toml` and `deploy/*.service` carry a Bitwarden project UUID: an
  identifier, not a secret. Keep it in the units, or move it to the mise env on the box.
- [ ] **License (Sam).** None chosen yet; the repo has no `LICENSE` file.
- [x] **`.superpowers/` is ignored** (`.gitignore`), along with `data/`, `.env` and `.env.*`. `labels/` and `reports/` are fine to publish.
- [x] **Sample data is synthetic.** `dashboard/sample/` is generated by `dashboard/sample/make_sample.py`: real-shaped
  tickers, every price, size and time invented (seeded, fixed clock). `DASHBOARD_SHOW_BOOKS = False`, so books are null.

  `tests/test_dashboard_static.py` (both pin `https://github.com/samuellee19/venue-arb`, a guess until the repo exists).

- [ ] **Repo links the page.** Replace the `https://<server>` placeholder under "Live dashboard" in `README.md` with the deployed URL, and check that it opens.
